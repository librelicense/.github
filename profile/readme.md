# ⚖️ The Libre License Framework (LLF)

> **Empower your community. Protect your work. Governed by Libre Collective.**

Welcome to the **Libre License Framework (LLF)** - an independent, standalone licensing suite governed and maintained
by **Libre Collective**. Designed for software maintainers, data scientists, machine learning engineers, and digital
creators, **LLF** provides clear, enforceable, single-restriction licensing for software, datasets, AI models, and
digital assets without the overhead of complex legal jargon.

---

## ⚡ Core Framework Features

- **🛡️ Single-Restriction Model:** Every License Option enforces precisely **_one_** clear legal restriction upon an
  otherwise maximally permissive baseline.
- **🧩 Modular License Stacking:** Combine License Options (ex: attribution, non-commercial, network source, or cloud
  protection) to build tailored legal protections.
- **🌐 Universal Digital Coverage:** Purpose-built to protect software source code, AI/ML model weights, database
  records, technical documentation, and media assets.
- **💬 Plain-Language Precision:** Written in direct, accessible English so developers, creators, and legal teams
  immediately understand their rights and obligations.
- **💼 Commercial and Dual-Licensing Ready:** Built-in Copyright Holder rights reservations allow creators to monetize
  via commercial waivers and enterprise licenses.

## 📜 Master Registry of License Options

The framework provides an **extensible family of purpose-built License Options** organized into two primary
categories: **Prohibition Options (`LN*L`)** and **Condition Options (`L*L`)**.

| Shortcode | Full Name                          | Type        | Singular Restriction                                   |
| --------- | ---------------------------------- | ----------- | ------------------------------------------------------ |
| `LCRL`    | Libre Credit Required License V1   | Condition   | Credit required in all Distributions                   |
| `LNCL`    | Libre No-Commercial License V1     | Prohibition | Prohibits Commercial Use and patent exploitation       |
| `LSTL`    | Libre Same-Terms License V1        | Condition   | Derivative Works must carry the same LSTL license      |
| `LNSL`    | Libre Network-Source License V1    | Condition   | Disclose source when serving over a network            |
| `LSSL`    | Libre Single-Source License V1     | Condition   | Submit Derivative Works to Upstream Repository         |
| `LNDL`    | Libre No-Distribution License V1   | Prohibition | Prohibits public Distribution and network hosting      |
| `LNAL`    | Libre No-AI License V1             | Prohibition | Prohibits AI/ML training and evaluation use            |
| `LNHL`    | Libre No-Harm License V1           | Prohibition | Prohibits weapons, surveillance, and human rights harm |
| `LRDL`    | Libre Release Date License V1      | Condition   | Restricts until Release Date, then converts            |
| `LNML`    | Libre No-Modification License V1   | Prohibition | Prohibits all modifications and Distribution           |
| `LNRL`    | Libre No-Cloud-Resale License V1   | Prohibition | Prohibits managed cloud service resale                 |
| `LNBL`    | Libre No-Data-Brokering License V1 | Prohibition | Prohibits commercial data reselling and brokering      |
| `LPDL`    | Libre Public-Domain License V1     | Condition   | Zero restrictions; Public Domain dedication            |
| `LUTL`    | Libre Usage Threshold License V1   | Condition   | Restricts Commercial Use when thresholds are exceeded  |
